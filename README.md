# メール一括整理（MailBulkTidy）

Webメールでは一度に100件までしか選べないときに、**特定の差出人からのメールを200件・1000件単位でまとめてゴミ箱へ移す**ためのアプリです。Mac・Windowsで使えます。

- 完全には削除しません。**ゴミ箱フォルダへ移すだけ**なので、間違えてもWebメールから元に戻せます
- パスワードや接続設定は**どこにも保存しません**。アプリを閉じると接続も切れます
- メールソフトやGmailの設定は一切変更しません

> 100件以下なら、Webメールの画面で操作するほうが手軽です。

---

## はじめに必ずお読みください

- **POPで受信している方へ**：Gmailやメールソフトが「POP」でメールを取り込んでいる場合、まだ取り込まれていないメールは、このアプリで移動すると取り込まれなくなります。
- **ゴミ箱の自動削除**：お使いのメールサービスでゴミ箱に保存期限が設定されていると、期限が来たメールは消えます。
- **容量**：ゴミ箱のメールもメールボックスの容量に数えられます。容量を空けたい場合は、確認後にWebメールでゴミ箱を空にしてください。
- 大事なメールがある場合は、事前にバックアップをとってください。

## 起動のしかた

このアプリには、Apple・Microsoft の「署名」を付けていません（費用がかかるため）。そのため、**初回だけ**警告が出ます。以下の手順で開いてください。

### Mac

1. ダウンロードした `MailBulkTidy-mac.zip` をダブルクリックして展開します
2. 出てきた `MailBulkTidy` を「アプリケーション」フォルダへ移します（任意）
3. `MailBulkTidy` をダブルクリックします。「開けません」「開発元を確認できません」と表示されたら「完了」（または「キャンセル」）を押します
4. **システム設定 → プライバシーとセキュリティ** を開き、下のほうにある「"MailBulkTidy"は開発元を確認できないため…」の横の **「このまま開く」** を押します
5. 確認画面でもう一度「このまま開く」を押し、Macのパスワードを入力します

2回目からは、普通にダブルクリックで開けます。
（macOS 14以前では、アプリを**右クリック → 開く** でも起動できます）

### Windows

1. ダウンロードした `MailBulkTidy-windows.zip` を右クリック → **すべて展開** します（zipのまま中を開いて起動しないでください）
2. 展開したフォルダ `MailBulkTidy` の中の **`MailBulkTidy.exe`** をダブルクリックします
3. 「WindowsによってPCが保護されました」と表示されたら、**「詳細情報」→「実行」** を押します

## 使い方

1. **ログイン**：サーバー名・メールアドレス・パスワードを入力して「ログイン」
   - サーバー名は、メールソフトの設定で使う「受信メールサーバー（IMAP）」の名前です
   - **さくらのレンタルサーバ**の場合は、独自ドメインではなく**初期ドメイン**（`xxxx.sakura.ne.jp`）を入力してください
2. **移動先の確認**：ゴミ箱フォルダが自動で選ばれます。違う場合は一覧から選び直してください
3. **検索**：整理したい差出人のメールアドレスを**全部**入力して「検索」
   - アドレスが完全に一致するメールだけが対象です。似ているアドレスや、差出人が複数あるメールは対象外になり、件数と理由が表示されます
   - 下に見本が表示されるので、対象が正しいか確認してください
4. **移動**：注意事項を読んでチェックを入れ、「200件」または「1000件」のボタンを押します。確認画面で「はい」を押すと移動します
   - はじめての方は、まず200件で試して、Webメールのゴミ箱に入ったことを確認してください

## 困ったとき

| 表示 | 対処 |
|---|---|
| サーバーの証明書を確認できませんでした | サーバー名を確認してください。さくらの場合は初期ドメイン（`xxxx.sakura.ne.jp`）を使います |
| ログインできませんでした | メールアドレスとパスワードを確認してください。何度も失敗すると、サーバー側で一時的に接続が制限されることがあります |
| MOVE / UIDPLUS に対応していない | そのメールサーバーでは、安全に移動できないため使えません |
| 件数が一致しないため止めました | 他のメールソフトが同時に操作していると起こることがあります。Webメールで受信箱とゴミ箱を確認してから、もう一度検索してください |
| 接続が切れた可能性があります | もう一度ログインして検索してください。移動済みのメールはゴミ箱にあり、受信箱に残っている分だけが対象になります |

**途中でやめた・止まったとき**も、もう一度検索すれば残りの分から続けられます。

### 間違えて移したとき

Webメールでゴミ箱を開き、メールを選んで受信箱へ移してください。

---

## 記録ファイル

移動のたびに、次の場所へ記録（CSV）を残します。差出人アドレス・件数・結果だけで、件名や本文、パスワードは記録しません。不要になったら削除してかまいません。

- Mac：`/Users/（ユーザー名）/MailBulkTidy/move_log.csv`
- Windows：`C:\Users\（ユーザー名）\MailBulkTidy\move_log.csv`

---

## 安全のための仕組み

- 証明書を検証した暗号化接続（IMAPS・993番ポート）のみ
- 差出人アドレスの完全一致。From欄に複数のアドレスがあるもの・読み取れないものは対象外
- 移動の前に、件数・差出人・移動先を表示して確認
- 移動のあと、「受信箱から消えたか」「ゴミ箱の件数が増えたか」を確認し、一致しなければ停止
- ほかのメールを巻き込む操作（受信箱全体への削除の確定など）は行わない
- 完全削除・ゴミ箱を空にする機能はありません
